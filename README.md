# RSViewer

RSViewer 是一个面向个人使用的桌面媒体管理与查看工具，计划用于浏览本地目录和 NAS 中的漫画、图片与视频。

项目当前处于早期开发阶段，已具备由 RSViewer 自有数据库驱动的本地漫画库、分页封面、搜索、详情预览、收藏、本地浏览历史和漫画阅读器。运行时不再读取或修改外部 `eh.db`；画廊索引、EhViewer 兼容元数据、分类、播放列表、归类、收藏、历史、进度和任务状态统一保存在 `app/data/rsviewer.db`。左侧导航底部通过“漫画 / 视频”按钮切换媒体模式：漫画模式在顶部显示本地资源、收藏、在线资源、历史记录和正在下载，视频模式当前只显示资源入口；“新窗口”位于“设置”正上方，可在同一进程内打开完整的第二个 RSViewer 窗口。在线资源已接入根目录的 `eh_tool_refactored.py`，直接沿用其中的 E-Hentai / ExHentai HTML 列表请求、解析与翻页流程；设置中可填写自己的 EH Cookie/Token，选择系统代理、直连或手动 HTTP(S) 代理并设置超时。默认收起的标签栏分为分类、播放列表和树状归类，支持新增、分配、移至未分类和右键删除；搜索栏和标签栏均有可配置的全局快捷键，搜索按钮还支持可关闭的悬停自动展开，空搜索离开后收起、有内容时保持。资源卡片右键通过独立的可搜索选择窗口分配分类、播放列表和树状归类，避免大量标签子菜单越界或显示不全，同时支持单项和复选批量操作，也可剥离章节号、卷数和常见元数据后在完整本地库中搜索相似章节或重复画廊。在具体播放列表画廊中，还可右键将单本或复选漫画直接从当前播放列表移除。资源卡片也可批量收藏，收藏页与历史页复用本地资源的首次加载结果，不会重复扫描大型漫画库。历史页按最近访问展示本地漫画，并预留独立在线历史入口。播放列表支持编排、继续播放和相邻漫画前后翻动；详情按命名空间显示主题化胶囊标签，标题、元数据和标签文字均可选中复制，播放列表、归类、页数、阅读进度、下载完整性、文件大小和可见性等低频字段收纳在“查看详细”中。大型漫画库采用惰性加载，详情预览固定每页 40 张。阅读器支持窗口内/全屏、四向翻页、长图滚动、跳页、缩放、拖动、自动翻页、预读、进度恢复，以及按文件内容识别并播放扩展名错误的 GIF 动图。视频播放功能仍待实现。

本地资源搜索栏在悬停时仍会临时展开；点击搜索按钮可把它锁定为常驻，再点击一次解除锁定并恢复“移入展开、移出收起”。快捷键和“搜索相似画廊”会直接常驻打开，已有搜索词时仍保持展开，避免正在使用的筛选突然消失。

多个窗口共享进程内协调器、下载/更新线程池和任务所有权：下载仍是全局最多 3 项，画廊更新仍是全局最多 1 项，同一 GID 不会因多窗口而重复执行。在任一窗口进行收藏、历史、阅读进度、分类/播放列表/归类修改、下载、更新、整理或数据源切换后，其他窗口会即时更新轻量状态或从同一数据库重载；从另一个窗口暂停、继续或删除任务时，操作会转交给实际持有 Worker 的窗口。

在线资源卡片现在会在应用内打开共享画廊详情页，也可通过 Card、精简列表或 Extended 卡片右键“下载”直接创建基础下载任务，无需先进入详情。搜索栏旁的日历按钮可按选定日期使用 EH/EX 原生 Seek 定位，当前关键词会一同生效，定位后仍可继续翻页；链接按钮可展开画廊网址输入框，这里只接受完整的 E-Hentai / ExHentai `/g/{gid}/{token}/` HTTPS 地址。已下载的在线卡片还可右键“在资源管理器中打开”对应本地目录；本地资源卡片和本地详情提供相同入口，本地复选模式下只打开实际右键的画廊。后台沿用当前站点 provider 的同一会话直接 GET `/g/{gid}/{token}/` HTML 页面，展示完整元数据、分组标签、20 张一页的缩略预览和只读评论区；评论作者、时间、评分和正文均可选中复制。评论正文中的 EH/EX 画廊地址会显示为应用内跳转按钮，点击可打开前作、续作或其他关联画廊，返回时恢复上一详情；外站和非画廊链接保持普通文字。评论画廊引用会随评论快照保存在自有数据库中。点击预览或“开始在线阅读”后复用本地漫画阅读器，按需请求单图 HTML 中的站点展示图。详情页同时提供基础下载和原图下载；基础下载读取 `#img` 站点展示图，原图下载读取单图页提供的同站 `fullimg` 链接。两种下载都保留 EhViewer 目录和数据库字段兼容，实际状态只写 RSViewer 自有数据库，断线、失败或主动暂停后可继续缺失页面。发表评论尚未实现。

点击在线下载后，在线卡片会立即显示绿色下载图标并占用该 GID，避免重复点击；SQLite 任务与兼容索引写入、目标目录创建、有效 `.thumb` 落盘和本地条目读取由多窗口共享的单线程预登记任务在后台完成，不会因数据库锁等待或 NAS 目录访问阻塞界面。预登记会保存当前已有的标题、GID、token、分类和页数；成功后再获取完整详情，并由下载 Worker 补齐评论、页面 token、sidecar 和图片。绿色图标表示“正在加入下载、已加入下载或已在本地资源中”。登记和完成阶段只增量更新这一部画廊，不会重新扫描整个本地库或清空当前分类、搜索和页码。

本地分类采用一份统一的内存倒排索引：分类、播放列表和树状归类分别映射到所属 GID 集合，“显示全部”从同一索引取得全部 GID。SQLite 关系表仍是重启后的持久化事实；加载时重建索引，单本下载登记和标签操作成功时增量更新，因此各视图不会再各自扫描并解释漫画条目上的分类字段。

## 运行

建议使用 Python 3.10 或更高版本：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

## 从 EhViewer 迁移

已有 `eh.db` 可通过一次性脚本导入 RSViewer 自有数据库，建议先退出正在运行的 RSViewer。源文件始终以只读模式打开；默认合并同名记录，加入 `--replace` 可先清空 EhViewer 兼容表再导入：

```powershell
python scripts/import_ehviewer_database.py "D:\path\to\eh.db"
python scripts/import_ehviewer_database.py "D:\path\to\eh.db" --replace
```

默认目标是 `app/data/rsviewer.db`，也可用 `--database` 指定其他 RSViewer 数据库。导入后应用不再需要原 `eh.db`。需要交给 EhViewer 使用时，在设置页点击“导出 EhViewer 数据库”，选择目标位置；程序会在后台新建包含 EhViewer v7 完整表结构的 `eh.db`，校验完整性后原子替换目标文件。

## EH 标签联想

将 EH 标签翻译仓库克隆到项目根目录的 `Database/` 后，先执行一次导入：

```powershell
python scripts/import_eh_tags.py
```

脚本默认读取 `Database/database/*.md`，把命名空间、英文原始标签、中文名称、描述和外部链接以完整快照写入 `app/data/rsviewer.db`。导入可重复执行，更新标签仓库后再次运行即可；也可用 `--source` 和 `--database` 指定其他路径。`Database/` 和自有运行数据库均已忽略，不会随项目提交。

程序启动时会把已导入标签加载为共享内存检索表，本地资源、收藏、本地历史和在线资源搜索框使用同一套补全。输入中文译名或英文标签片段时，标签候选用两行显示，例如第一行 `other：full color`、第二行“全彩”，确认后写入 `o:"full color"`。已确认条件以空格分隔，可继续输入并补全其他标签；本地搜索会把 EH 缩写语法还原为完整命名空间进行匹配，在线搜索则原样提交给 EH/EX。

搜索框还共享一份持久化历史：点击输入框时可查看最近查询，继续输入时匹配的历史始终排在标签候选之前。点击搜索图标或按 Enter 确认后写入历史，重复查询会移动到最前；历史最多保存 20 条，设置页可调整为 5、10、15 或 20 条。

## 在线资源

在线资源直接调用 [eh_tool_refactored.py](eh_tool_refactored.py) 中的 `EhData`：使用 `requests.Session` 请求 EH/EX 画廊列表页，通过 `BeautifulSoup` 与 `lxml` 解析原有五种列表样式，并沿用页面返回的上一页、下一页 URL。搜索词使用同一列表页的 `f_search` 参数，没有改接其他 API。

[RefactoredEhOnlineProvider](app/sources/eh_online_source.py) 只负责把程序设置中的站点、Cookie、代理与超时注入爬虫，并把原脚本结果转换为在线资源卡片。Cookie 和代理不再写死在脚本中；网络请求只在用户进入空站点、搜索、刷新、翻页、点击画廊详情、切换未缓存的预览分页、阅读或下载未缓存页面、加载未缓存封面时发生。翻页 URL、画廊 URL、单图页 URL 与图片 URL 会限制在当前 EH/EX 站点、EH 图片域名及 `hath.network` CDN 内。

E-Hentai 与 ExHentai 各自保留当前搜索、日期定位、页码、翻页历史、滚动位置和最近访问页面，切换站点时可立即恢复；首次进入空站点会自动加载首页，顶部“刷新”可强制重取当前页。结果顶部使用单个动态图标按钮在封面卡片、116px 高的精简列表和横向 Extended 三种视图间循环；精简列表只显示标题、类型、发布者和页数，不请求封面。选择会保存为本地默认视图；Card 与精简列表共用站点 Compact 数据，可直接重排内存页，只有切入或切出 Extended 时才通过 `inline_set=dm_l/dm_e` 同步站点模式并重取字段。三种布局都会按 GID 判断画廊是否已存在于本地资源，已下载画廊的左上角显示绿色下载图标。布局切换期间会在内存中复用当前页已加载封面，不再重新读取或下载。评分从 EH 星级精灵位置转换为 `0–5` 数值，不再显示 CSS 样式。封面使用可配置并发数的独立线程池，并按站点缓存在本机 `app/cache/online_thumbnails/`；设置页可选择 1 小时至 30 天的过期时间，过期或损坏文件会在再次访问时自动更新。本地资源封面也会缓存按控件尺寸裁切后的位图，滚动时不再逐帧重复平滑缩放。

“跟随系统”会读取 Windows 当前用户的代理设置，并兼容系统将同一个 HTTP CONNECT 代理端点同时用于 HTTP 与 HTTPS 请求的常见配置；无需把相同地址重复填写到“手动设置”。

在线详情、预览和阅读使用最近访问 20 个画廊的内存 LRU：再次进入可复用详情、封面、已访问的预览分页和缩略图。阅读图片每个画廊最多缓存 5 页，并受 128 MiB 总预算约束；超过画廊数量或图片预算时按最近最少使用顺序自动淘汰，不写入数据库。

在线详情的下载任务由所有画廊共享同一个专用后台线程池，设置中的 1–3 表示最多同时运行的画廊数量；单个画廊仍按页顺序下载。“正在下载”页面可一键全部开始或全部暂停，并把任务明确标为“基础下载”“直接下载原图”或“本地画廊下载原图”。每个活动任务显示当前速度和页数进度，图片响应流每 0.5 秒更新一次区间速度，页面标题汇总活动任务速度；图片流式连接或响应体连续 15 秒没有进展时会自动关闭本次请求并重试，不需要依靠手动暂停恢复。任务保留 EhViewer `VERSION2` `.ehviewer`、`.thumb` 和八位页码目录格式，兼容元数据、评论、额外信息、断点和原图阶段均写入 RSViewer 自有 SQLite。

尚未落地的在线画廊选择“下载原图”时，下载内容直接成为根目录画廊页，并被永久标记为原图下载画廊。已有本地画廊选择原图时，文件先下载到同目录的 `original/`，标准图和 `.ehviewer` 保持不变；完成后详情可在“标准画廊 / 原图画廊”之间切换预览和阅读。“原图替换”会先把标准图移动到 `history/del/`，再把 `original/` 内容提升到根目录；备份不会自动删除，只有用户确认“删除压缩图”后才清理。下载、替换与清理阶段均可在意外退出后继续。每一页会独立请求 `fullimg`：存在时保存原图，仅当该页合法单图页确实没有原图链接时才改用该页基础图，并在 SQLite 中持久记录每页的 `original` / `base` 类型。中断续传和未来“更新到最新”都会沿用已有页类型，新页面仍优先尝试原图，因此允许同一画廊安全包含原图与基础图。本地卡片继续使用原图画廊的彩色渐变边框；只要存在基础图回退页，左上角就显示醒目的紫色圆点。详情右上角对全原图画廊显示彩色 `ORIGINAL` 标签，对混合画廊显示金色 `X ORIGINAL` 与紫色 `Y BASE` 标签；混合画廊仍可预览、阅读和执行原图替换。正在下载或待替换的原图画廊显示暗黄色边框，未完成的基础下载显示右上角黄点。

打开本地画廊详情时，程序会按需读取 `.ehviewer`，用其中的总页数和逐页 token 对照磁盘上的八位页码图片。详情显示真实总页数、已下载页数和完整状态；实际文件少于 sidecar 总页数时仍按完整页码生成预览格，已有页读取本地图片，缺失页只请求对应的在线缩略图。点击缺失页进入阅读器后会仅下载该页到原 EhViewer 目录再展示，纯在线画廊阅读仍只使用内存缓存，不落盘。即使自有数据库已记录为下载完成，详情仍会提供“基础下载”，并可直接从配置的 EH/EX 源站补回缺失或损坏页面。详情中的“同步信息”只请求对应画廊 HTML，用于刷新标签、评论和元数据，不会下载图片或改变下载状态；若页面的 `#gnd` 提供更新版本，详情会提示当前画廊是旧父画廊。两个下载入口各自在按钮下方显示进度，阅读器工具栏也会显示基础下载的页数进度和实时速度。逐页落盘只替换对应预览格和阅读页，不会重复刷新整块画廊信息或重建当前预览分页。

## 本地画廊版本更新

本地详情“同步信息”检测到新版本后会持久显示“更新到最新”。更新任务先原子写入 `new.ehviewer` 和目录内 `new.json`，再用“页码-页索引-page token”临时文件名标记旧图片，按最新顺序重排，删除页移入 `history/removed/`，并只下载新增页。图片通过 `.part` 校验后原子改名；恢复时会重新验证并幂等修复实际文件，不仅依赖 checkpoint。重复出现的 page token 会按出现次数分别配对，不会覆盖或遗漏页面。

完成后旧 sidecar 归档到 `history/`，新 sidecar 晋升为 `.ehviewer`，并在同一个自有数据库事务中迁移 GID、分类、播放列表、收藏、历史和阅读进度关联，同时刷新 `DOWNLOADS.TIME`；本地画廊完成原图替换时也会刷新该时间，使最新优先排序反映实际内容变更。完成 checkpoint 会立即从更新管理隐藏，启动时也会修正旧版本遗留的“阶段已完成但状态仍在更新”记录。画廊更新全局只允许一个任务实际执行，其余任务显示为等待更新并按入队顺序自动继续。未完成的原画廊会先自动补齐；更新期间阅读、同步和补页被锁定，播放列表会自动跳过该画廊。中断任务可从独立“更新管理”页继续，也可删除任务记录；删除只移除 RSViewer 的任务索引，画廊文件及目录 checkpoint 会保留。

漫画导航的“整理”页可由右上角按钮后台扫描漫画根目录，以响应式封面卡片网格列出本地存在但自有数据库 `DOWNLOADS` 中没有登记的直接子目录。结果支持复选、全选和右键批量操作：有效 `VERSION2` `.ehviewer` 目录可按原目录名同步到自有数据库的 `DOWNLOADS`、`DOWNLOAD_DIRNAME`、`Gallery_Tags` 及下载/同步状态表；同步时会逐页验证图片，完整有效的资源标记为完成，不完整或损坏资源保留为可继续任务。缺少或损坏 sidecar 的目录只允许删除。删除操作必须二次确认，并移入 Windows 回收站，不执行不可恢复的递归删除。

本地资源卡片右键新增“移入回收站”，复选时可批量处理。软删除只从自有数据库的兼容表移除画廊、目录映射和标签登记，本地图片目录保持原位；RSViewer 会保存原始数据库行、用户分类关系和删除状态。漫画导航的“回收站”以封面卡片展示这些资源，支持复选、全选、工具栏或右键还原和彻底删除。还原不需确认，并把原始记录写回同一自有数据库；彻底删除会先要求确认，再删除本地图片目录和 RSViewer 关联记录。操作中断会保留可重试状态，软删除目录也不会被“整理”页当成未登记资源。

## 计划支持

- 本地目录、Windows 映射盘及 UNC 网络共享路径
- 漫画与图片集的封面浏览和阅读进度
- 常见视频格式的管理与播放
- RSViewer 自有 SQLite 媒体索引，以及按需导入/导出 EhViewer v7 `eh.db`
- 本地缩略图缓存
