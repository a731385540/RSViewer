# RSViewer

RSViewer 是一个面向个人使用的桌面媒体管理与查看工具，计划用于浏览本地目录和 NAS 中的漫画、图片与视频。

项目当前处于早期开发阶段，已具备由 RSViewer 自有数据库驱动的本地漫画库、分页封面、搜索、详情预览、收藏、本地浏览历史和漫画阅读器。运行时不再读取或修改外部 `eh.db`；画廊索引、EhViewer 兼容元数据、分类、归类、收藏、历史、进度和任务状态统一保存在 `data/rsviewer.db`。旧播放列表表及数据仅为现有数据库兼容保留，不再作为独立界面或新业务功能使用。左侧导航底部通过“漫画 / 视频”按钮切换媒体模式；“新窗口”位于“设置”正上方，可在同一进程内打开完整的第二个 RSViewer 窗口。默认收起的标签栏只保留分类和树状归类，支持新增、分配、移至未分类和右键删除；资源卡片右键通过独立的可搜索选择窗口分配分类或归类，也支持单项和复选批量操作。本地详情操作栏可使用同一选择窗口替换当前分类，选择“未分类”会清除分类。资源卡片还可批量收藏、搜索相似画廊，收藏页与历史页复用本地资源的首次加载结果。详情按命名空间显示主题化标签，归类、页数、阅读进度、下载完整性、文件大小和可见性等低频字段收纳在“查看详细”中。阅读器支持窗口内/全屏、四向翻页、长图滚动、跳页、缩放、拖动、自动翻页、预读和进度恢复；翻页控件上方保留稳定的悬停区域，鼠标移入才显示快速进度条，拖动可即时跳到目标页。从分类或归类打开画廊时，会按当前选择的时间或自定义顺序建立完整阅读序列，末页继续翻页或首页向前翻页可自动跨书，也可随时使用工具栏“下一本”或默认快捷键 `Ctrl+PageDown` 跳转。视频播放功能仍待实现。

本地资源搜索栏在悬停时仍会临时展开；点击搜索按钮可把它锁定为常驻，再点击一次解除锁定并恢复“移入展开、移出收起”。快捷键和“搜索相似画廊”会直接常驻打开，已有搜索词时仍保持展开，避免正在使用的筛选突然消失。

多个窗口共享进程内协调器、下载/更新线程池和任务所有权：同时执行的画廊下载全局最多 3 项，所有活动画廊再共用最多 6 个页面图片线程；画廊更新仍是全局最多 1 项，同一 GID 不会因多窗口而重复执行。在任一窗口进行收藏、历史、阅读进度、分类/归类修改、下载、更新、整理或数据源切换后，其他窗口会即时更新轻量状态或从同一数据库重载；从另一个窗口暂停、继续或删除任务时，操作会交给实际持有 Worker 的窗口。

在线资源卡片现在会在应用内打开共享画廊详情页，也可通过 Card、精简列表或 Extended 卡片右键“下载”直接创建基础下载任务，无需先进入详情。设置的在线资源分组提供“画廊标记”：可分别维护“标题包含”和 Tag 规则，任一规则命中时三种在线卡片都会显示深红边框；标题采用不区分大小写的包含匹配，Tag 可填写完整 `namespace:tag` 或裸 tag 名并进行精确匹配，保存后当前结果立即刷新。搜索栏旁的日历按钮可按选定日期使用 EH/EX 原生 Seek 定位，当前关键词会一同生效，定位后仍可继续翻页；链接按钮可展开画廊网址输入框，这里只接受完整的 E-Hentai / ExHentai `/g/{gid}/{token}/` HTTPS 地址。已下载的在线卡片还可右键“在资源管理器中打开”对应本地目录；本地资源卡片和本地详情提供相同入口，本地复选模式下只打开实际右键的画廊。后台沿用当前站点 provider 的同一会话直接 GET `/g/{gid}/{token}/` HTML 页面，展示完整元数据、分组标签、按账户设置实际返回的 20/40 张一页缩略预览和只读评论区；评论作者、时间、评分和正文均可选中复制。评论正文中的 EH/EX 画廊地址会显示为应用内跳转按钮，点击可打开前作、续作或其他关联画廊，返回时恢复上一详情；外站和非画廊链接保持普通文字。评论画廊引用会随评论快照保存在自有数据库中。点击预览或“开始在线阅读”后复用本地漫画阅读器，按需请求单图 HTML 中的站点展示图。详情页同时提供基础下载和原图下载；基础下载读取 `#img` 站点展示图，原图下载读取单图页提供的同站 `fullimg` 链接。两种下载都保留 EhViewer 目录和数据库字段兼容，实际状态只写 RSViewer 自有数据库，断线、失败或主动暂停后可继续缺失页面。发表评论尚未实现。

点击在线下载后，在线卡片会立即显示绿色下载图标并占用该 GID，避免重复点击；SQLite 任务与兼容索引写入、目标目录创建、有效 `.thumb` 落盘和本地条目读取由多窗口共享的单线程预登记任务在后台完成，不会因数据库锁等待或 NAS 目录访问阻塞界面。预登记会保存当前已有的标题、GID、token、分类和页数；成功后再获取完整详情，并由下载 Worker 补齐评论、页面 token、sidecar 和图片。绿色图标表示“正在加入下载、已加入下载或已在本地资源中”。登记和完成阶段只增量更新这一部画廊，不会重新扫描整个本地库或清空当前分类、搜索和页码。

本地分类采用一份统一的内存倒排索引：分类和树状归类分别映射到所属 GID 集合，“显示全部”从同一索引取得全部 GID，父归类会合并全部后代节点并去重。SQLite 关系表仍是重启后的持久化事实；加载时重建索引，单本下载登记和标签操作成功时增量更新。本地资源页标题显示当前分类名称，树状归类显示 `父级/子级/...` 完整路径，选择“显示全部漫画”时恢复为“本地资源”。分类、未分类和每个归类节点都可各自保存一套“自定”顺序：尚未创建时排序下拉框显示 `+`，对话框默认按时间倒序列出完整成员，可拖动整行或多选后整体上下移动；保存后下拉框显示“自定”，选中时才出现编辑按钮。父归类针对合并后代并去重的全集保存独立顺序，新成员按时间倒序追加到末尾。“显示全部”、收藏和历史不提供自定义顺序。从当前分类或归类打开画廊时，阅读序列复用当前时间或自定义排序，但不受搜索词和分页影响；从显示全部、收藏、历史、相似结果或直接详情进入时不建立跨书序列。新增归类完成后只更新归类树和实际被分配的漫画，不重新处理整个本地库。

本地与在线资源卡片右上角竖排显示下载和阅读两个状态点：白色表示未下载/未读，黄色表示下载不完整，黄绿色表示阅读中，绿色表示下载完成或曾经读完。`.ehviewer` 默认的第 1 页起始值不会再让未读画廊变成阅读中；用户实际进入 RSViewer 阅读器后，即使仍停在第 1 页也会正确记录为阅读中。读完状态不会因回翻而消失；本地卡片右键或详情操作栏可显式清空阅读记录，数据库墓碑会阻止旧 `.ehviewer` 进度重新出现。在线与本地详情页的语言、作者关键标签及完整标签卡会优先显示数据库中已导入的 EH 中文译名；没有中文记录的标签保留原始 tag，悬停仍可查看原始 `namespace:tag`。标题中选中文字后可右键按字面量搜索本地英语/原标题，也可把所选文本自动转换为带双引号的精确短语，在当前 E-Hentai / ExHentai 源中搜索。在线搜索页会显示返回来源画廊的入口；进入结果详情后先返回结果列表，再返回原详情，并恢复原有详情跳转栈或分类/归类阅读序列。最近一次本地相似结果跨重启保留，“查看详细”旁的按钮会打开唯一的非模态相似画廊窗口，双击结果进入同一窗口的详情，返回后仍是当前结果列表。

画廊详情的每个关键标签和完整标签都可右键选择“复制 Tag”。复制内容使用原始 EH 标签和 namespace 缩写，并带精确匹配后缀，例如界面显示“语言：汉语”时复制为 `l:"chinese$"`；可直接粘贴到本地或在线资源搜索框。

## 运行

建议使用 Python 3.10 或更高版本：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

## Windows 打包

安装 PyInstaller 后使用仓库提供的 spec 构建单文件桌面程序：

```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean RSViewer.spec
```

产物位于 `dist/RSViewer.exe`。`RSViewer.spec` 会把 `app/resource/qss` 的 light/dark 样式目录完整复制到 PyInstaller 运行目录；不要使用 `pyi-makespec main.py` 生成的默认空 `datas` 配置直接构建，否则详情、在线资源和设置页样式无法打开。

单文件 exe 解包到 `_MEI...` 的内容只用于读取资源。可写状态统一保存在 exe 同级的 `data` 目录：`config.json` 是设置，`rsviewer.db` 是画廊索引及用户状态，`cache/online_thumbnails` 是可删除的在线封面缓存。源码运行使用项目根目录下相同的 `data` 结构；路径不受启动时当前工作目录影响。缺少配置或数据库时会自动生成默认文件；若目标文件尚不存在，程序会优先迁移旧版项目内 `app/config`、`app/data` 或 `%LOCALAPPDATA%\RSViewer` 中的现有数据，且不会覆盖已经存在的新文件。移动 exe 时应连同 `data` 目录一起移动。

## 从 EhViewer 迁移

已有 `eh.db` 可通过一次性脚本导入 RSViewer 自有数据库，建议先退出正在运行的 RSViewer。源文件始终以只读模式打开；默认合并同名记录，加入 `--replace` 可先清空 EhViewer 兼容表再导入：

```powershell
python scripts/import_ehviewer_database.py "D:\path\to\eh.db"
python scripts/import_ehviewer_database.py "D:\path\to\eh.db" --replace
```

默认目标是 `data/rsviewer.db`，也可用 `--database` 指定其他 RSViewer 数据库。导入后应用不再需要原 `eh.db`。需要交给 EhViewer 使用时，在设置页点击“导出 EhViewer 数据库”，选择目标位置；程序会在后台新建包含 EhViewer v7 完整表结构的 `eh.db`，校验完整性后原子替换目标文件。

脚本默认目标适用于源码运行。若要直接导入打包版使用的数据库，请退出 RSViewer 后增加 `--database "D:\path\to\RSViewer\data\rsviewer.db"`，其中路径是 exe 所在目录；不要在 RSViewer 运行时覆盖数据库。

## EH 标签联想

将 EH 标签翻译仓库克隆到项目根目录的 `Database/` 后，先执行一次导入：

```powershell
python scripts/import_eh_tags.py
```

脚本默认读取 `Database/database/*.md`，把命名空间、英文原始标签、中文名称、描述和外部链接以完整快照写入 `data/rsviewer.db`。导入可重复执行，更新标签仓库后再次运行即可；也可用 `--source` 和 `--database` 指定其他路径。`Database/` 和自有运行数据库均已忽略，不会随项目提交。

程序启动时会把已导入标签加载为共享内存检索表，本地资源、收藏、本地历史和在线资源搜索框使用同一套补全。输入中文译名或英文标签片段时，标签候选用两行显示，例如第一行 `other：full color`、第二行“全彩”，确认后写入 `o:"full color"`。已确认条件以空格分隔，可继续输入并补全其他标签；本地搜索会把 EH 缩写语法还原为完整命名空间进行匹配，在线搜索则原样提交给 EH/EX。

搜索框还共享一份持久化历史：点击输入框时可查看最近查询，继续输入时匹配的历史始终排在标签候选之前。点击搜索图标或按 Enter 确认后写入历史，重复查询会移动到最前；历史最多保存 20 条，设置页可调整为 5、10、15 或 20 条。

## 在线资源

在线资源直接调用 [eh_tool_refactored.py](eh_tool_refactored.py) 中的 `EhData`：使用 `requests.Session` 请求 EH/EX 画廊列表页，通过 `BeautifulSoup` 与 `lxml` 解析原有五种列表样式，并沿用页面返回的上一页、下一页 URL。搜索词使用同一列表页的 `f_search` 参数，没有改接其他 API。

[RefactoredEhOnlineProvider](app/sources/eh_online_source.py) 只负责把程序设置中的站点、Cookie、代理与超时注入爬虫，并把原脚本结果转换为在线资源卡片。登录会话首次请求列表前会在后台读取一次同站配置页，使站点下发账户能力 Cookie；因此列表会实际遵循账户设置的每页 25/50/100 条结果，不再因仅注入登录 Cookie 而回退为 25 条。初始化失败时仍继续请求普通列表。Cookie 和代理不再写死在脚本中；网络请求只在用户进入空站点、搜索、刷新、翻页、点击画廊详情、切换未缓存的预览分页、阅读或下载未缓存页面、加载未缓存封面时发生。翻页 URL、画廊 URL、单图页 URL 与图片 URL 会限制在当前 EH/EX 站点、EH 图片域名及 `hath.network` CDN 内。

E-Hentai 与 ExHentai 的列表没有稳定数字页码，因此在线资源不再显示或维护“第 N 页”。两个站点各自保留当前搜索、日期定位、响应游标、滚动位置和最近访问结果，切换站点时可立即恢复；“上一页”“下一页”只在当前服务器响应提供对应 URL 时启用，日期定位结果若同时提供两个方向就可同时翻动。首次进入空站点会自动加载首页，顶部“刷新”可强制重取当前游标结果。结果顶部使用单个动态图标按钮在封面卡片、116px 高的精简列表和横向 Extended 三种视图间循环；封面卡片采用更紧凑的 229px 宽布局，精简列表只显示标题、类型、发布者和页数且不请求封面。选择会保存为本地默认视图；Card 与精简列表共用站点 Compact 数据，可直接重排内存结果，只有切入或切出 Extended 时才通过 `inline_set=dm_l/dm_e` 同步站点模式并重取字段。三种布局都会按 GID 判断画廊是否已存在于本地资源，已下载画廊的左上角显示绿色下载图标。布局切换期间会在内存中复用当前结果已加载封面，不再重新读取或下载。评分从 EH 星级精灵位置转换为 `0–5` 数值，不再显示 CSS 样式。封面使用可配置并发数的独立线程池，并按站点缓存在本机 `data/cache/online_thumbnails/`；设置页可选择 1 小时至 30 天的过期时间，过期或损坏文件会在再次访问时自动更新。本地资源封面也会缓存按控件尺寸裁切后的位图，滚动时不再逐帧重复平滑缩放。

“跟随系统”会读取 Windows 当前用户的代理设置，并兼容系统将同一个 HTTP CONNECT 代理端点同时用于 HTTP 与 HTTPS 请求的常见配置；无需把相同地址重复填写到“手动设置”。

在线详情、预览和阅读使用最近访问 20 个画廊的内存 LRU：再次进入可复用详情、封面、已访问的预览分页和缩略图。阅读图片每个画廊最多缓存 5 页，并受 128 MiB 总预算约束；超过画廊数量或图片预算时按最近最少使用顺序自动淘汰，不写入数据库。

在线下载有两层独立并发设置：“画廊下载并发数”1–3 控制同时执行的画廊数量，超出的画廊保持排队；“图片下载线程数”1–6 由所有活动画廊共同使用。比如前者设为 1、后者设为 6，加入 10 个画廊时只有 1 个画廊运行、9 个排队，运行中的画廊最多同时下载 6 页；前者设为 3 时，3 个活动画廊公平共享同一组图片线程，不会各自创建 6 个线程。“正在下载”页面可一键全部开始或全部暂停，并把任务明确标为“基础下载”“直接下载原图”或“本地画廊下载原图”。每个活动任务显示其并发页面的汇总速度和页数进度，图片响应流约每 1 秒更新一次区间速度；首次取得速度前显示“测速中”，之后在换页和重试间隙保留最近的有效速度，不再反复跳回“测速中”。页面标题汇总所有活动画廊速度；图片流式连接或响应体连续 15 秒没有进展时会自动关闭本次请求并重试。任务保留 EhViewer `VERSION2` `.ehviewer`、`.thumb` 和八位页码目录格式，逐页原子落盘，兼容元数据、评论、额外信息、断点和原图阶段均写入 RSViewer 自有 SQLite。

尚未落地的在线画廊选择“下载原图”时，下载内容直接成为根目录画廊页，并被永久标记为原图下载画廊。已有本地画廊选择原图时，文件先下载到同目录的 `original/`，标准图和 `.ehviewer` 保持不变；完成后详情可在“标准画廊 / 原图画廊”之间切换预览和阅读。“原图替换”会先把标准图移动到 `history/del/`，再把 `original/` 内容提升到根目录；备份不会自动删除，只有用户确认“删除压缩图”后才清理。下载、替换与清理阶段均可在意外退出后继续。每一页会独立请求 `fullimg`：存在时保存原图，仅当该页合法单图页确实没有原图链接时才改用该页基础图，并在 SQLite 中持久记录每页的 `original` / `base` 类型。中断续传和未来“更新到最新”都会沿用已有页类型，新页面仍优先尝试原图，因此允许同一画廊安全包含原图与基础图。本地卡片继续使用原图画廊的彩色渐变边框；只要存在基础图回退页，左上角就显示醒目的紫色圆点。详情右上角对全原图画廊显示彩色 `ORIGINAL` 标签，对混合画廊显示金色 `X ORIGINAL` 与紫色 `Y BASE` 标签；混合画廊仍可预览、阅读和执行原图替换。正在下载或待替换的原图画廊显示暗黄色边框，未完成的基础下载显示右上角黄点。

打开本地画廊详情时，程序会按需读取 `.ehviewer`，用其中的总页数和逐页 token 对照磁盘上的八位页码图片。详情显示真实总页数、已下载页数和完整状态；实际文件少于 sidecar 总页数时仍按完整页码生成预览格，已有页读取本地图片，缺失页只请求对应的在线缩略图。点击缺失页进入阅读器后会仅下载该页到原 EhViewer 目录再展示，纯在线画廊阅读仍只使用内存缓存，不落盘。即使自有数据库已记录为下载完成，详情仍会提供“基础下载”，并可直接从配置的 EH/EX 源站补回缺失或损坏页面。详情中的“同步信息”只请求对应画廊 HTML，用于刷新标签、评论和元数据，不会下载图片或改变下载状态；若页面的 `#gnd` 提供更新版本，详情会提示当前画廊是旧父画廊。两个下载入口各自在按钮下方显示进度，阅读器工具栏也会显示基础下载的页数进度和实时速度。逐页落盘只替换对应预览格和阅读页，不会重复刷新整块画廊信息或重建当前预览分页。

## 本地画廊版本更新

本地详情“同步信息”检测到新版本后会持久显示“更新到最新”。更新任务先原子写入 `new.ehviewer` 和目录内 `new.json`，再用“页码-页索引-page token”临时文件名标记旧图片，按最新顺序重排，删除页移入 `history/removed/`，并只下载新增页。图片通过 `.part` 校验后原子改名；恢复时会重新验证并幂等修复实际文件，不仅依赖 checkpoint。重复出现的 page token 会按出现次数分别配对，不会覆盖或遗漏页面。

完成后旧 sidecar 归档到 `history/`，新 sidecar 晋升为 `.ehviewer`，并在同一个自有数据库事务中迁移 GID、分类、旧播放列表兼容关系、归类、收藏、历史和阅读进度关联，同时刷新 `DOWNLOADS.TIME`；本地画廊完成原图替换时也会刷新该时间，使最新优先排序反映实际内容变更。完成 checkpoint 会立即从更新管理隐藏，启动时也会修正旧版本遗留的“阶段已完成但状态仍在更新”记录。画廊更新全局只允许一个任务实际执行，其余任务显示为等待更新并按入队顺序自动继续。未完成的原画廊会先自动补齐；更新期间阅读、同步和补页被锁定，阅读序列会自动跳过该画廊。中断任务可从独立“更新管理”页继续，也可删除任务记录；删除只移除 RSViewer 的任务索引，画廊文件及目录 checkpoint 会保留。

漫画导航的“整理”页可由右上角按钮后台扫描漫画根目录，以响应式封面卡片网格列出本地存在但自有数据库 `DOWNLOADS` 中没有登记的直接子目录。结果支持复选、全选和右键批量操作：有效 `VERSION2` `.ehviewer` 目录可按原目录名同步到自有数据库的 `DOWNLOADS`、`DOWNLOAD_DIRNAME`、`Gallery_Tags` 及下载/同步状态表；同步时会逐页验证图片，完整有效的资源标记为完成，不完整或损坏资源保留为可继续任务。缺少或损坏 sidecar 的目录只允许删除。删除操作必须二次确认，并移入 Windows 回收站，不执行不可恢复的递归删除。

本地资源卡片右键新增“移入回收站”，复选时可批量处理。软删除只从自有数据库的兼容表移除画廊、目录映射和标签登记，本地图片目录保持原位；RSViewer 会保存原始数据库行、用户分类关系和删除状态。漫画导航的“回收站”以封面卡片展示这些资源，支持复选、全选、工具栏或右键还原和彻底删除。还原不需确认，并把原始记录写回同一自有数据库；彻底删除会先要求确认，再删除本地图片目录和 RSViewer 关联记录。操作中断会保留可重试状态，软删除目录也不会被“整理”页当成未登记资源。

## 计划支持

- 本地目录、Windows 映射盘及 UNC 网络共享路径
- 漫画与图片集的封面浏览和阅读进度
- 常见视频格式的管理与播放
- RSViewer 自有 SQLite 媒体索引，以及按需导入/导出 EhViewer v7 `eh.db`
- 本地缩略图缓存

## 第三方组件

界面使用 [PySide6-Fluent-Widgets](https://github.com/zhiyiYo/PyQt-Fluent-Widgets)。本项目仅用于个人、非商业用途；使用和分发时仍需遵守相关第三方组件的许可证。
