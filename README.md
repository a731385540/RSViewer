# RSViewer

RSViewer 是一个面向个人使用的桌面媒体管理与查看工具，计划用于浏览本地目录和 NAS 中的漫画、图片与视频。

项目当前处于早期开发阶段，已具备外部 EhViewer 本地漫画库、分页封面、搜索、详情预览、收藏、本地浏览历史和漫画阅读器。在线资源已接入根目录的 `eh_tool_refactored.py`，直接沿用其中的 E-Hentai / ExHentai HTML 列表请求、解析与翻页流程；设置中可填写自己的 EH Cookie/Token，选择系统代理、直连或手动 HTTP(S) 代理并设置超时。默认收起的标签栏分为分类、播放列表和树状归类，支持新增、分配、移至未分类和右键删除；搜索栏和标签栏均有可配置的全局快捷键，搜索按钮还支持可关闭的悬停自动展开，空搜索离开后收起、有内容时保持。资源卡片右键通过独立的可搜索选择窗口分配分类、播放列表和树状归类，避免大量标签子菜单越界或显示不全，同时支持单项和复选批量操作，也可剥离章节号、卷数和常见元数据后在完整本地库中搜索相似章节或重复画廊。在具体播放列表画廊中，还可右键将单本或复选漫画直接从当前播放列表移除。资源卡片也可批量收藏，收藏页与历史页复用本地资源的首次加载结果，不会重复扫描大型漫画库。历史页按最近访问展示本地漫画，并预留独立在线历史入口。播放列表支持编排、继续播放和相邻漫画前后翻动；详情按命名空间显示主题化胶囊标签。大型漫画库采用惰性加载，详情预览固定每页 40 张。阅读器支持窗口内/全屏、四向翻页、长图滚动、跳页、缩放、拖动、自动翻页、预读、进度恢复，以及按文件内容识别并播放扩展名错误的 GIF 动图。分类修改目标 EhViewer 既有数据，播放列表、归类、收藏、历史和进度保存在 RSViewer 独立数据库。视频播放功能仍待实现。

## 运行

建议使用 Python 3.10 或更高版本：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

## EH 标签联想

将 EH 标签翻译仓库克隆到项目根目录的 `Database/` 后，先执行一次导入：

```powershell
python scripts/import_eh_tags.py
```

脚本默认读取 `Database/database/*.md`，把命名空间、英文原始标签、中文名称、描述和外部链接以完整快照写入 `app/data/rsviewer.db`。导入可重复执行，更新标签仓库后再次运行即可；也可用 `--source` 和 `--database` 指定其他路径。`Database/` 和自有运行数据库均已忽略，不会随项目提交。

程序启动时会把已导入标签加载为共享内存检索表，本地资源、收藏、本地历史和在线资源搜索框使用同一套补全。输入中文译名或英文标签片段时，标签候选用两行显示，例如第一行 `other：full color`、第二行“全彩”，确认后写入 `o:"full color"`。已确认条件以空格分隔，可继续输入并补全其他标签；本地搜索会把 EH 缩写语法还原为完整命名空间进行匹配，在线搜索则原样提交给 EH/EX。

搜索框还共享一份持久化历史：点击输入框时可查看最近查询，继续输入时匹配的历史始终排在标签候选之前。点击搜索图标或按 Enter 确认后写入历史，重复查询会移动到最前；历史最多保存 20 条，设置页可调整为 5、10、15 或 20 条。

## 在线资源

在线资源直接调用 [eh_tool_refactored.py](eh_tool_refactored.py) 中的 `EhData`：使用 `requests.Session` 请求 EH/EX 画廊列表页，通过 `BeautifulSoup` 与 `lxml` 解析原有五种列表样式，并沿用页面返回的上一页、下一页 URL。搜索词使用同一列表页的 `f_search` 参数，没有改接其他 API。

[RefactoredEhOnlineProvider](app/sources/eh_online_source.py) 只负责把程序设置中的站点、Cookie、代理与超时注入爬虫，并把原脚本结果转换为在线资源卡片。Cookie 和代理不再写死在脚本中；网络请求只在用户进入空站点、搜索、刷新、翻页或加载未缓存封面时发生。翻页 URL 与封面 URL 会限制在 EH/EX 及其图片域名内。

E-Hentai 与 ExHentai 各自保留当前搜索、页码、翻页历史、滚动位置和最近访问页面，切换站点时可立即恢复；首次进入空站点会自动加载首页，顶部“刷新”可强制重取当前页。结果可在紧凑卡片与横向 Extended 视图之间切换，选择会保存为本地默认视图，并在后台沿用原爬虫会话调用列表页自身的 `inline_set=dm_l/dm_e`，同步站点账户默认模式后重取当前页；Extended 因而可取得并展示分命名空间标签，若源页面仍为 Minimal/Minimal+ 且没有标签则给出提示。评分从 EH 星级精灵位置转换为 `0–5` 数值，不再显示 CSS 样式。封面使用可配置并发数的独立线程池，并按站点缓存在本机 `app/cache/online_thumbnails/`；设置页可选择 1 小时至 30 天的过期时间，过期或损坏文件会在再次访问时自动更新。

## 计划支持

- 本地目录、Windows 映射盘及 UNC 网络共享路径
- 漫画与图片集的封面浏览和阅读进度
- 常见视频格式的管理与播放
- EhViewer `eh.db` 兼容（浏览默认只读，显式分类操作更新 `DOWNLOADS.LABEL`）与独立的 RSViewer 播放列表、树状归类和阅读进度数据库
- SQLite 媒体索引和本地缩略图缓存

## 第三方组件

界面使用 [PySide6-Fluent-Widgets](https://github.com/zhiyiYo/PyQt-Fluent-Widgets)。本项目仅用于个人、非商业用途；使用和分发时仍需遵守相关第三方组件的许可证。
