# RSViewer

RSViewer 是一个面向个人使用的桌面媒体管理与查看工具，计划用于浏览本地目录和 NAS 中的漫画、图片与视频。

项目当前处于早期开发阶段，已具备外部 EhViewer 本地漫画库、分页封面、搜索、详情预览、收藏、本地浏览历史和漫画阅读器。左侧导航底部通过“漫画 / 视频”按钮切换媒体模式：漫画模式在顶部显示本地资源、收藏、在线资源、历史记录和正在下载，视频模式当前只显示资源入口，“设置”始终位于两个模式按钮下方。在线资源已接入根目录的 `eh_tool_refactored.py`，直接沿用其中的 E-Hentai / ExHentai HTML 列表请求、解析与翻页流程；设置中可填写自己的 EH Cookie/Token，选择系统代理、直连或手动 HTTP(S) 代理并设置超时。默认收起的标签栏分为分类、播放列表和树状归类，支持新增、分配、移至未分类和右键删除；搜索栏和标签栏均有可配置的全局快捷键，搜索按钮还支持可关闭的悬停自动展开，空搜索离开后收起、有内容时保持。资源卡片右键通过独立的可搜索选择窗口分配分类、播放列表和树状归类，避免大量标签子菜单越界或显示不全，同时支持单项和复选批量操作，也可剥离章节号、卷数和常见元数据后在完整本地库中搜索相似章节或重复画廊。在具体播放列表画廊中，还可右键将单本或复选漫画直接从当前播放列表移除。资源卡片也可批量收藏，收藏页与历史页复用本地资源的首次加载结果，不会重复扫描大型漫画库。历史页按最近访问展示本地漫画，并预留独立在线历史入口。播放列表支持编排、继续播放和相邻漫画前后翻动；详情按命名空间显示主题化胶囊标签，标题、元数据和标签文字均可选中复制，播放列表、归类、页数、阅读进度、下载完整性、文件大小和可见性等低频字段收纳在“查看详细”中。大型漫画库采用惰性加载，详情预览固定每页 40 张。阅读器支持窗口内/全屏、四向翻页、长图滚动、跳页、缩放、拖动、自动翻页、预读、进度恢复，以及按文件内容识别并播放扩展名错误的 GIF 动图。分类修改目标 EhViewer 既有数据，播放列表、归类、收藏、历史和进度保存在 RSViewer 独立数据库。视频播放功能仍待实现。

在线资源卡片现在会在应用内打开共享画廊详情页，也可通过 Card/Extended 卡片右键“下载”直接创建任务，无需先进入详情。后台沿用当前站点 provider 的同一会话直接 GET `/g/{gid}/{token}/` HTML 页面，展示完整元数据、分组标签、20 张一页的缩略预览和只读评论区；评论作者、时间、评分和正文均可选中复制。点击预览或“开始在线阅读”后复用本地漫画阅读器，按需请求单图 HTML 中的站点展示图，并保留翻页、跳页、缩放、长图、全屏、方向键、自动翻页和相邻页预读。详情页或右键任务都可把整本画廊下载到设置中的 EhViewer 漫画根目录，并写入兼容的 `eh.db` 业务表；设置中的“默认下载分类”决定新画廊写入的 `LABEL`，默认为未分类，已有画廊继续下载时不会覆盖原分类。断线、失败或主动暂停后可继续缺失页面。该链路不调用官方或第三方 API；发表评论尚未实现。

## 运行

建议使用 Python 3.10 或更高版本：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

## EH 标签联想

将 EH 标签翻译仓库克隆到项目根目录的 `Database/` 后，先执行一次导入：

```powershell
python scripts/import_eh_tags.py
```

脚本默认读取 `Database/database/*.md`，把命名空间、英文原始标签、中文名称、描述和外部链接以完整快照写入 `app/data/rsviewer.db`。导入可重复执行，更新标签仓库后再次运行即可；也可用 `--source` 和 `--database` 指定其他路径。`Database/` 和自有运行数据库均已忽略，不会随项目提交。

程序启动时会把已导入标签加载为共享内存检索表，本地资源、收藏、本地历史和在线资源搜索框使用同一套补全。输入中文译名或英文标签片段时，标签候选用两行显示，例如第一行 `other：full color`、第二行“全彩”，确认后写入 `o:"full color"`。已确认条件以空格分隔，可继续输入并补全其他标签；本地搜索会把 EH 缩写语法还原为完整命名空间进行匹配，在线搜索则原样提交给 EH/EX。

搜索框还共享一份持久化历史：点击输入框时可查看最近查询，继续输入时匹配的历史始终排在标签候选之前。点击搜索图标或按 Enter 确认后写入历史，重复查询会移动到最前；历史最多保存 20 条，设置页可调整为 5、10、15 或 20 条。

## 在线资源

在线资源直接调用 [eh_tool_refactored.py](eh_tool_refactored.py) 中的 `EhData`：使用 `requests.Session` 请求 EH/EX 画廊列表页，通过 `BeautifulSoup` 与 `lxml` 解析原有五种列表样式，并沿用页面返回的上一页、下一页 URL。搜索词使用同一列表页的 `f_search` 参数，没有改接其他 API。

[RefactoredEhOnlineProvider](app/sources/eh_online_source.py) 只负责把程序设置中的站点、Cookie、代理与超时注入爬虫，并把原脚本结果转换为在线资源卡片。Cookie 和代理不再写死在脚本中；网络请求只在用户进入空站点、搜索、刷新、翻页、点击画廊详情、切换未缓存的预览分页、阅读或下载未缓存页面、加载未缓存封面时发生。翻页 URL、画廊 URL、单图页 URL 与图片 URL 会限制在当前 EH/EX 站点、EH 图片域名及 `hath.network` CDN 内。

E-Hentai 与 ExHentai 各自保留当前搜索、页码、翻页历史、滚动位置和最近访问页面，切换站点时可立即恢复；首次进入空站点会自动加载首页，顶部“刷新”可强制重取当前页。结果顶部使用单个动态图标按钮在紧凑卡片与横向 Extended 视图之间切换，选择会保存为本地默认视图，并在后台沿用原爬虫会话调用列表页自身的 `inline_set=dm_l/dm_e`，同步站点账户默认模式后重取当前页；Extended 因而可取得并展示分命名空间标签，若源页面仍为 Minimal/Minimal+ 且没有标签则给出提示。两种布局都会按 GID 判断画廊是否已存在于本地资源，已下载画廊的左上角显示绿色下载图标。布局切换期间会在内存中复用当前页已加载封面，不再重新读取或下载。评分从 EH 星级精灵位置转换为 `0–5` 数值，不再显示 CSS 样式。封面使用可配置并发数的独立线程池，并按站点缓存在本机 `app/cache/online_thumbnails/`；设置页可选择 1 小时至 30 天的过期时间，过期或损坏文件会在再次访问时自动更新。

“跟随系统”会读取 Windows 当前用户的代理设置，并兼容系统将同一个 HTTP CONNECT 代理端点同时用于 HTTP 与 HTTPS 请求的常见配置；无需把相同地址重复填写到“手动设置”。

在线详情、预览和阅读使用最近访问 20 个画廊的内存 LRU：再次进入可复用详情、封面、已访问的预览分页和缩略图。阅读图片每个画廊最多缓存 5 页，并受 128 MiB 总预算约束；超过画廊数量或图片预算时按最近最少使用顺序自动淘汰，不写入外部 `eh.db`。

在线详情的“下载画廊”由所有任务共享的专用后台线程池执行，设置中的 1–6 表示最多同时运行的画廊数量，不是每个画廊各自创建相同数量的线程；单个画廊仍按页顺序下载。“正在下载”页面可一键全部开始或全部暂停，也保留单项开始、暂停和删除。每个活动任务会显示平滑后的实时下载速度，首张图片完成前显示“测速中”，页面顶部显示所有活动任务的总速度。任务先把标题、GID/token、分类、发布者、评分、页数和命名空间标签事务写入外部 `eh.db` 的既有 `DOWNLOADS`、`DOWNLOAD_DIRNAME` 与 `Gallery_Tags`，保留已有分类和归档字段；评论、额外元数据、进度及错误写入 RSViewer 自有 SQLite v9。随后收集全部 `/s/{page-token}/{gid}-{page}` 标识，在下载目录写入 EhViewer `VERSION2` `.ehviewer`、`.thumb` 和八位页码图片。外部条目、目录和封面就绪后，画廊会在下载仍进行时立即进入本地资源的未分类范围，同时更新在线卡片的绿色本地标记；`.ehviewer` 就绪后，已打开的本地详情也会自动重新读取总页数和 page token。图片沿用在线阅读链路下载 `#img` 站点展示图，不使用 `fullimg` 原始文件接口。失败或重启后可在详情页或独立“正在下载”页面继续；即使上次退出发生在外部记录、下载目录或 `.ehviewer` 创建之前，程序也会根据自有任务记录中的站点、GID/token 重新获取完整画廊信息，再恢复标准初始化和下载流程。任务会校验并跳过已有有效图片，只补齐缺失或损坏页，完成后自动移出任务页。外部数据库不新增任何表、列或索引。完成后本地资源、收藏/历史共享数据和在线下载标记即时刷新，并自动显示目标画廊；本地详情同步展示上传者、发布时间、评分、语言和文件大小等已保存信息。

打开本地画廊详情时，程序会按需读取 `.ehviewer`，用其中的总页数和逐页 token 对照磁盘上的八位页码图片。详情显示真实总页数、已下载页数和完整状态；实际文件少于 sidecar 总页数时仍按完整页码生成预览格，已有页读取本地图片，缺失页只请求对应的在线缩略图。点击缺失页进入阅读器后会仅下载该页到原 EhViewer 目录再展示，纯在线画廊阅读仍只使用内存缓存，不落盘。即使 `eh.db` 已记录为下载完成，详情仍会提供“检查并补齐”，并可直接从配置的 EH/EX 源站补回缺失或损坏页面。详情中的“同步信息”只请求对应画廊 HTML，用于刷新标签、评论和元数据，不会下载图片或改变下载状态；若页面的 `#gnd` 提供更新版本，详情会提示当前画廊是旧父画廊。下载进度条位于下载按钮下方，按钮本身显示已完成页数和总页数；阅读器工具栏也会显示当前画廊的下载页数进度和实时速度。逐页落盘只替换对应预览格和阅读页，不会重复刷新整块画廊信息或重建当前预览分页。

## 本地画廊版本更新

本地详情“同步信息”检测到新版本后会持久显示“更新到最新”。更新任务先原子写入 `new.ehviewer` 和目录内 `new.json`，再用“页码-页索引-page token”临时文件名标记旧图片，按最新顺序重排，删除页移入 `history/removed/`，并只下载新增页。图片通过 `.part` 校验后原子改名；恢复时会重新验证实际文件，不仅依赖 checkpoint。

完成后旧 sidecar 归档到 `history/`，新 sidecar 晋升为 `.ehviewer`，并迁移外部 `eh.db` GID 及 RSViewer 的分类、播放列表、收藏、历史和阅读进度关联。未完成的原画廊会先自动补齐；更新期间阅读、同步和补页被锁定，播放列表会自动跳过该画廊。中断任务可从独立“更新管理”页继续。

## 计划支持

- 本地目录、Windows 映射盘及 UNC 网络共享路径
- 漫画与图片集的封面浏览和阅读进度
- 常见视频格式的管理与播放
- EhViewer `eh.db` 兼容（浏览默认只读；显式分类与在线下载更新既有业务表）与独立的 RSViewer 播放列表、树状归类、阅读进度及在线下载状态数据库
- SQLite 媒体索引和本地缩略图缓存
